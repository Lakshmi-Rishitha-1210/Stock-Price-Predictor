# Stock Price Predictor

This project predicts stock prices based on historical data using an LSTM model.

## Features
- Fetches historical stock data from Yahoo Finance.
- Preprocesses data with scaling and sequence creation.
- Trains an LSTM model for time series prediction.
- Evaluates and plots predicted vs actual prices.

## Requirements
- Python 3.7+
- See `requirements.txt` for Python dependencies.
